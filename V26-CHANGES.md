# AMURLAND ONLINE V26

## Изменения

1. Окно покупки свободной недвижимости появляется через 1 секунду после завершения движения фишки.
2. Кнопка завершения хода начинает заметно пульсировать через 7 секунд после начала хода, когда игрок уже может завершить ход. На устройствах с настройкой уменьшения движения вместо анимации отображается яркая обводка.
3. Добавлен общий чат комнаты для текстовых сообщений. Сообщения проходят серверную проверку, ограничены 300 символами, последние 100 сообщений синхронизируются между участниками и сохраняются при переподключении.
4. Все остальные функции предыдущей версии сохранены.

## Проверка

- `npm run build` — сборка shared, server и client;
- `npm test` — тесты игровых правил.
