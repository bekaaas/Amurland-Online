# AMURLAND ONLINE V25 — исправления 15.10.2026

## Исправлено

1. **Тюрьма и фантомные перемещения.** При неудачной попытке выбросить дубль кубики проигрывают анимацию броска, однако фишка остаётся на клетке тюрьмы. Движение запускается лишь в случае реального перемещения согласно серверному состоянию. Возврат-прыжок после неудачной попытки больше не показывается.
2. **Задержка окон оплаты и игровых событий.** Сообщения о попадании, оплате и карточки отображаются после того, как фишка завершит перемещение, с небольшой дополнительной паузой. Окно подтверждения оплаты появляется ещё немного позже. До подтверждения нельзя завершить ход; деньги на панели игроков также визуально обновляются после прибытия фишки. Сервер при этом продолжает оставаться единственным источником истины.
3. **Не больше одной постройки за полный ход.** Можно построить только один дом **или** отель за полный ход, на любом объекте игрока. Дополнительный бросок при дубле не позволяет строить повторно. Запрет контролируется сервером и отображается на карточках собственности. На следующем полном ходе разрешается новая постройка.

## Тестирование

- `npm run typecheck` — успешно, общие типы, сервер и клиент.
- `npm test` — четыре регрессионных теста, пройдены.
- `npm run build` — сервер и общие типы собраны; этап Vite в среде проверки недоступен из-за Windows-only бинарных компонентов старых `node_modules`. В ZIP папка `node_modules` намеренно исключена: команда `npm install` на Windows установит правильные зависимости для вашей платформы.

## Как запустить на Windows

1. Распакуйте ZIP, откройте папку проекта в VS Code.
2. Установите Node.js 20+ и выполните `npm install` в терминале корня проекта (или запустите `START-AMURLAND-WINDOWS.bat`, он установит зависимости автоматически).
3. Выполните `npm run dev` либо запустите `START-AMURLAND-WINDOWS.bat`.
4. Откройте `http://localhost:5173`.
5. Для проверки откройте ещё одно окно браузера и присоединитесь к комнате.

Музыка, графика и существующая игровая логика V24 сохранены.
