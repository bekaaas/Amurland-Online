# AMURLAND ONLINE — V28 Lite Internet Rooms

## Подключение друзей без VPN

Локальный режим запускается из VS Code и доступен по `http://localhost:5173`. Для игры через интернет проект включает `render.yaml`: он публикует сайт и Socket.IO сервер вместе на одном публичном HTTPS-адресе. После публикации создайте комнату и отправьте друзьям ссылку кнопкой **Скопировать приглашение**.

Пошаговая инструкция и ограничения бесплатного тестового хостинга: [DEPLOY-TO-RENDER.md](DEPLOY-TO-RENDER.md).

Чтобы уменьшить размер архива, из этой облегчённой сборки удалена только фоновая музыка и её панель управления. Чат, эффекты игровых звуков, интернет-комнаты и остальные игровые функции сохранены.

## Что изменено в V28

- добавлена конфигурация публикации игры и игрового сервера на Render;
- сервер в production раздаёт frontend вместе с Socket.IO;

- переход по ссылке автоматически заполняет код комнаты;
- сохранён локальный запуск проекта через VS Code.

## Функции V13, сохранённые в V16

### Стартовая жеребьёвка

- после запуска матча каждый игрок бросает одну кость;
- игроки автоматически сортируются от большего результата к меньшему;
- при одинаковом результате только игроки с ничьёй перебрасывают кость;
- первый обычный ход начинается только после окончательного определения очереди;
- результат генерируется только сервером.

### Выбор фигурки в лобби

- доступно 12 вариантов фигурок;
- одна фигурка не может быть выбрана двумя игроками;
- занятые варианты автоматически блокируются;
- выбор синхронизируется всем участникам комнаты.

### Строительство только в свой ход

- сервер запрещает строительство дома или отеля во время чужого хода;
- кнопка строительства на карточке собственности также блокируется на чужом ходу;
- продажа зданий и залог по-прежнему доступны для погашения долгов по действующим правилам.

### Обновлённое поле

- линия цвета владельца идёт по внешней стороне клетки: сверху, справа, снизу или слева в зависимости от стороны поля;
- обычные дома теперь отображаются как небольшие модели домов вместо прямоугольников;
- отель отображается как увеличенная красная модель здания;
- фишки на поле увеличены для лучшей видимости.

## Функции V12, сохранённые в V16

### Покупка и собственность

- после попадания на свободную недвижимость появляется карточка с полной информацией;
- можно купить объект по указанной цене;
- если отказаться, объект автоматически переходит на аукцион;
- на поле отображается цвет владельца;
- у каждого игрока под полем есть постоянный блок «Мои карточки собственности»;
- карточки показывают цену, аренду, стоимость дома/отеля, залог и текущие постройки.

### Аренда

- аренда автоматически рассчитывается и переводится владельцу;
- полный цветовой комплект удваивает базовую аренду незастроенных улиц;
- аренда увеличивается при строительстве домов и отеля;
- для станций аренда зависит от количества станций владельца;
- для коммунальных предприятий используется сумма кубиков ×4 или ×10;
- за заложенную собственность аренда не взимается.

### Дома и отели

- строить можно только при владении всей цветовой группой;
- строительство идёт равномерно;
- максимум 4 дома, затем отель;
- если один объект группы заложен, строительство запрещено;
- здания можно продавать банку за половину стоимости;
- продажа тоже выполняется равномерно.

### Залог

- незастроенную недвижимость можно заложить банку;
- игрок получает залоговую стоимость;
- выкуп стоит залоговую стоимость + 10%;
- заложенную недвижимость можно включать в сделку;
- при получении заложенной недвижимости новый владелец платит 10% сбор.

### Trade

Кнопка `🤝 Trade` теперь полностью работает.

В сделку можно включать с обеих сторон:

- деньги;
- одну или несколько объектов недвижимости;
- карточки бесплатного выхода из тюрьмы.

Получатель видит предложение и может принять или отклонить его. Сервер перед подтверждением повторно проверяет деньги, владельцев и допустимость передачи имущества.

### Аукцион

Если игрок не покупает свободную недвижимость:

- запускается общий аукцион;
- участвовать могут все небанкротные игроки;
- можно повышать ставку или выйти из аукциона;
- победитель автоматически оплачивает ставку и получает карточку собственности.

### Тюрьма

Поддерживаются три способа выхода:

- заплатить ₸50 до броска;
- использовать карточку выхода;
- попытаться выбросить дубль.

После трёх неудачных попыток игрок обязан заплатить ₸50. Три дубля подряд в обычном ходу отправляют игрока в тюрьму.

### Шанс / Общественная казна

Добавлено по 16 собственных карточек для каждой колоды. Поддерживаются:

- получение денег;
- оплата денег;
- перемещение на конкретную клетку;
- движение назад;
- отправка в тюрьму;
- карточка выхода из тюрьмы;
- оплата каждому игроку;
- получение денег от каждого игрока;
- расходы на дома и отели.

### Долги и банкротство

Если денег не хватает для обязательной оплаты:

- возникает долг;
- ход нельзя завершить, пока долг не погашен;
- можно продавать здания;
- можно закладывать недвижимость;
- можно заключить сделку, чтобы получить деньги;
- если погасить долг невозможно, можно объявить банкротство;
- когда остаётся один небанкротный игрок, матч завершается и показывается победитель.

### Анимации и звук

Сохранены функции V11:

- фишки проходят поле по одной клетке;
- звук броска кубиков;

## Сервер — источник истины

Клиент не меняет деньги, позиции, владельцев, аренду, здания, сделки, результат аукциона, тюрьму или банкротство самостоятельно. Все команды проходят серверную проверку и затем синхронизируются всем игрокам через Socket.IO.

## Запуск на Windows

Самый простой вариант:

1. Распакуйте ZIP.
2. Откройте папку проекта.
3. Запустите `START-AMURLAND-WINDOWS.bat`.

Либо через VS Code:

```bash
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```

Backend:

```text
http://localhost:3001
```

## Проверка двумя игроками

1. Первый игрок создаёт комнату.
2. Второй открывает другой браузер / профиль / InPrivate и входит по коду.
3. Второй нажимает `Я готов`.
4. Host запускает матч.
5. Каждый игрок бросает одну кость для определения очереди.
6. После жеребьёвки играйте в автоматически определённом порядке.

Для двух разных игроков не используйте две обычные вкладки одного профиля браузера: они используют один `localStorage` и один `playerId`.
