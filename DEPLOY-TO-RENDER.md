# Игра с друзьями через интернет

В режиме VS Code игра открывается на `localhost`. Такой адрес доступен только на вашем компьютере и не подходит друзьям из других городов. Чтобы подключаться без VPN, один раз разместите игру на публичном сервере. В проект уже добавлена бесплатная конфигурация Render: сервер Socket.IO и сайт запускаются по одному HTTPS-адресу.

## Публикация

1. Создайте репозиторий на GitHub и загрузите туда распакованную папку `AMURLAND-ONLINE-V28` целиком.
2. Создайте бесплатный аккаунт на Render и выберите **New → Blueprint**.
3. Подключите GitHub-репозиторий с игрой. Render найдёт `render.yaml` и предложит создать сервис `amurland-online`.
4. Подтвердите создание сервиса. При первой публикации дождитесь статуса **Live**.
5. Откройте выданный Render адрес `https://...onrender.com`. На странице проверьте, что показано «Сервер подключён».
6. Создайте комнату. Нажмите **Скопировать приглашение** и отправьте ссылку друзьям. Они открывают эту же ссылку, вводят свои ники и нажимают **Войти по коду**.

Код комнаты также можно отправить отдельно: друзья открывают общую ссылку игры, вводят код и входят в комнату. Для игры из разных мест всем участникам нужно открывать именно публичный Render-адрес, а не `localhost`.

## Проверка в VS Code

Локальный запуск остаётся прежним:

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. Для проверки на одном компьютере можно открыть второй браузер в приватном окне. Для друзей через интернет используйте опубликованный Render-адрес.

## Ограничения бесплатного сервера

- Бесплатный сервер Render может выключаться после периода бездействия и запускаться примерно минуту при следующем подключении.
- Игровые комнаты хранятся в памяти сервера. Перезапуск или остановка сервиса завершит текущие матчи; для новой игры создайте комнату заново.
- Это бесплатный тестовый хостинг, поэтому доступность и задержка могут меняться.
